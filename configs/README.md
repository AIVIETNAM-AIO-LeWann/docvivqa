# Cấu hình

Lưu cấu hình từng thử nghiệm ở đây khi bắt đầu triển khai. Chưa có runner, model hoặc schema bắt buộc.

Các thông tin cần ghi: run ID, variant, đường dẫn dữ liệu/split, seed, commit baseline, evaluator, model/revision, prompt, tham số sinh và thư mục output.

API key đọc từ biến môi trường; không ghi vào cấu hình hoặc log.
